Presets

NE.Standard.UI.Extensions is a package of presets: static classes and extension methods that build the arrangements a screen writes over and over — a header band, a titled section, a message that stays in the page, two fields on one line, a pair of buttons at a form's foot — out of the built-in components. It adds no component of its own. Each preset returns an ordinary built-in — a stack panel, a container, a card, a surface, a button, a text, a paragraph or a key-value list — so everything they build is already rendered by the platform, and the package is server-only. A returned component takes the usual Set*, Bind* and On* calls after it, like any other.

It is installed separately:

dotnet add package NE.Standard.UI.Extensions

Like every package here it brings its namespace, NE.Standard.UI.Extensions, as a global using, so nothing below needs a using line; a project that sets NEStandardUIImplicitUsings to false writes its own.

A screen written with them

The same form without presets is a tree of stack panels, spacings and placements. With them it reads as the page it describes: sections down a column, two fields to a line, the address folded away while a box is ticked, and the buttons at the foot.

internal sealed class ShippingView : UIViewBase, IUIViewDefinition
{
    private const string FormId = "shipping";
    private const string SameAddressId = "shipping-same-address";

    public static string ViewKey => "shipping";

    protected override IVisualComponent? CreateHeader()
        => UIPage.Header("Shipping", "Where the parcel goes, and who signs for it.");

    protected override IVisualComponent CreateContent()
        => UILayout.Split(CreateForm(), CreateSummary(), sideSpan: 9);

    private static StackPanelComponent CreateForm()
        => UILayout.Stack(28,
            UIPage.Section("Recipient", null,
                UIForm.Row(
                    new TextInputComponent().SetTitle("First name").SetFormId(FormId).BindValue(nameof(ShippingController.FirstName)),
                    new TextInputComponent().SetTitle("Last name").SetFormId(FormId).BindValue(nameof(ShippingController.LastName))
                )
            ),
            UIPage.Section("Invoice address", "Only when it differs from the delivery address.",
                new CheckboxComponent(SameAddressId)
                    .SetTitle("Invoice goes to the delivery address")
                    .BindValue(nameof(ShippingController.SameAddress)),
                UILayout.Stack(16,
                    new TextInputComponent().SetTitle("Street and number").SetFormId(FormId).BindValue(nameof(ShippingController.Street)),
                    UIForm.Row(
                        new TextInputComponent().SetTitle("City").SetFormId(FormId).BindValue(nameof(ShippingController.City)),
                        new TextInputComponent().SetTitle("Postcode").SetFormId(FormId).BindValue(nameof(ShippingController.Postcode))
                    )
                )
                .ShownWhen(SameAddressId, false)
            ),
            UIButtons.Pair(
                UIButtons.Ghost("Back"),
                UIButtons.Primary("Continue").OnSubmit(FormId, nameof(ShippingController.ContinueAsync))
            )
        );

    private static CardComponent CreateSummary()
        => UIPage.Card("Your order", "Shipped within two working days.", UIDetails.List(
            ("Items", "3"),
            ("Weight", "2.4 kg"),
            ("Delivery", "Standard")
        ));
}

examples/DemoApp/Views/Screens/CheckoutView.cs in the repository is a full screen built this way.

UIPage — the regions of a page

Preset Builds
Header(string title, string? description = null, params IVisualComponent[] trailing) The band a page is headed by: the title, a muted line under it, and whatever is passed as trailing (a theme switcher, the signed-in person, the page's buttons) at the far end of the title's row at every width. From the medium breakpoint the title is in the display role on one line and the line runs to three lines under the title's columns. On a phone (below the medium breakpoint) the title is a title's size and wraps under itself when it is too long for its row, its first line level with the far end, and the line is one line, cut, under the whole band — so the band stays about a title's height (74 px at 390 px with two switchers) and leaves the screen to the page; its top padding there puts the title on the middle of the shell's drawer toggle. Keep a phone's far end to two or three controls: whatever it takes, the title gives up. Returns a ContainerComponent, usually from CreateHeader().
Section(string title, string? description, params IVisualComponent[] content) A titled part of a page: the heading, an optional muted line, and the content below it. The heading and its note sit closer to each other than to the content.
Card(string title, string? description, IVisualComponent content, string? icon = null) A CardComponent with its name (and optional line and icon) in the default header and one component as its content. The line is prose and wraps, however long; the name keeps one line.
Labelled(string label, IVisualComponent content) A component under an overline label: a value, a sample, a control with no title of its own.
Banner(SurfaceComponent message) A message from UIMessage laid across the top of the content: edge to edge, square, a rule under it, its mark in line with the header's name. Make it the content's first child, outside any padding of the content's own; it scrolls with the page. In the header region of a view with StickyHeader it stays as the page scrolls — on a phone it stands beside the drawer toggle there, and a tall one takes the screen from the page. 
protected override IVisualComponent? CreateHeader()
    => UIPage.Header("Projects", "Everything the team is building.", new ThemeSwitcherComponent());

UIMessage — a message that stays in the page

A toast leaves on its own and a validation line belongs to one field; a message the page keeps until it is no longer true — "Your trial ends in 3 days", "This workspace is read-only during maintenance", "2 errors in the form below" — is a UIMessage. It returns a SurfaceComponent drawn Tinted in the palette's colour for its severity, holding the severity's mark, a title, a body, an optional action and an optional ×.

Preset Builds
Info, Success, Warning, Danger (UIPhrase? title, UIPhrase? body = null, ButtonComponent? action = null, bool dismissible = false) A message in that severity. A title, a body or both: a message with neither throws.
Create(UIMessageSeverity severity, UIPhrase? title, UIPhrase? body, ButtonComponent? action = null, bool dismissible = false, string? icon = null) The same with the severity as an argument, and icon in place of the severity's mark.
Create(UIMessageSeverity severity, TextComponent? title, ParagraphComponent? body, …) The title or the body as a component of your own — bound to the controller, for words that change. The preset gives it the message's role and ink.
Severity Colour Mark To a screen reader
Info UIColorStyle.Info UIGlyphs.Info role="status": read when it is free
Success UIColorStyle.Success UIGlyphs.CheckCircle role="status"
Warning UIColorStyle.Warning UIGlyphs.Warning role="alert": read at once
Danger UIColorStyle.Danger UIGlyphs.Error role="alert"
  • The marks are the framework's own glyphs, drawn with no icon pack installed; icon takes any pack's name instead.
  • The role is the surface's LiveRegion (UILiveRegion.Status or Alert), so a message shown later — its Visibility bound — is read out as it appears, and a bound title or body as it changes. SetLiveRegion(null) on the result takes the role off a message that should only be read where the reader reaches it.
  • The action is your button, with its own command. It stands at the message's bottom end, as a toast's does: from the medium breakpoint beside the words, level with their last line; on a phone under them. An outlined one (UIButtons.Secondary) reads on every tint.
  • The × hides the message in the browser through one interaction from its click to the message's Visibility — nothing is sent, so a reload shows it again. The keyboard's focus goes on to the next control after the message, so a screen reader keeps its place. Its name is the framework's word "Dismiss" (ui.message.dismiss, shipped in Russian and Chinese). A message the server should stop showing binds its Visibility instead.
  • The title is in the subtitle role and the body in the body role, both in the page's own ink, which reads 4.5:1 on every severity's tint in both themes, the mark 3:1 or more.
UIMessage.Warning("Your trial ends in 3 days", "Billing starts on the 14th.",
    UIButtons.Secondary("Upgrade").OnClick(nameof(BillingController.Upgrade)),
    dismissible: true)

A verdict the server gives, read out as it arrives:

UIMessage.Create(UIMessageSeverity.Success, null, new ParagraphComponent().BindDescription(nameof(CheckoutController.PromoVerdict)))
    .BindVisibility(nameof(CheckoutController.PromoAppliedVisibility))

UIForm — the parts of a form besides its fields

Preset Builds
Field(IVisualComponent input, string hint) The input with a muted, wrapping hint under it: what may be typed, what it is for.
Row(params IVisualComponent[] fields), Row(double spacing, params IVisualComponent[] fields) Fields side by side in equal columns — a city and its postcode, a first and a last name — their tops level, so a field that grows a validation line does not move its neighbour; 16 pixels apart unless spacing says otherwise. 
UIForm.Field(new TextAreaComponent()
    .SetTitle("Invoice note")
    .SetMaxLength(200)
    .BindValue(nameof(CheckoutController.InvoiceNote)),
    "Printed on every invoice, two hundred characters at most.")

Row divides the twenty-four columns of the placement grid evenly, so it takes two, three, four or six fields and throws for any other count. It is UILayout.Columns(spacing, UIAlignment.Start, fields) underneath, so on a narrow screen the fields stand one under another, as below. A row of fields is UIForm.Row rather than UILayout.Columns, which centres a field against a taller neighbour.

UILayout — the arrangements

Preset Builds
Stack(double spacing = 12, params IVisualComponent[] children) Children down a column with the same spacing between each pair.
Row(double spacing = 8, params IVisualComponent[] children) Children along a row, wrapping onto the next line when the row is too narrow.
Columns(double spacing = 16, params IVisualComponent[] children) Children in equal columns — two, three, four or six of them; any other count throws.
Columns(double spacing, UIAlignment? cellAlignment, params IVisualComponent[] children) The same, every cell standing at cellAlignment — UIAlignment.Start holds the cells by the top, as UIForm.Row does; null lets each cell take its child's own.
Split(IVisualComponent main, IVisualComponent side, int sideSpan = 8, double spacing = 24) A main part with a side part to its right, the side taking sideSpan of the twenty-four columns.
Sidebar(IVisualComponent side, IVisualComponent main, int sideSpan = 8, double spacing = 24) The other way round: the side part first (a list, a tree, a filter rail), the main part beside it.

Each of Columns, Split and Sidebar stands its parts one under another on a narrow screen: two or three columns go side by side from the md tier, four or six columns, a split and a sidebar from xl. Side by side, a part keeps its own VerticalAlignment against a taller neighbour — a text, an input or a button is centred by default — and one that must stay at the top says SetVerticalAlignment(UIAlignment.Start).

The spacing comes first, so a stack with children always names it:

UILayout.Sidebar(CreateFilters(), UILayout.Stack(16,
    UIText.Title("Results"),
    CreateResults()
), sideSpan: 6)

UIButtons — a button in its type, and the rows buttons go in

Preset Builds
Primary, Accent, Secondary, Ghost, Danger, Link (string title, string? icon = null) A ButtonComponent of that type — Secondary is the outlined one.
Icon(string icon, string tooltip) An icon-only ghost button; the tooltip is its only name, so it is required.
Pair(ButtonComponent secondary, ButtonComponent primary) The pair at a form's foot: the safe answer first, the committing one last, both pushed to the far edge.
Toolbar(params ButtonComponent[] buttons) A row of buttons with a toolbar's tight spacing, from the near edge. 
UIButtons.Pair(
    UIButtons.Ghost("Keep it"),
    UIButtons.Danger("Delete project").OnClick(nameof(ProjectController.DeleteAsync))
)

UIButtons.Toolbar(
    UIButtons.Icon(MaterialIcons.Undo, "Undo"),
    UIButtons.Icon(MaterialIcons.Delete, "Delete")
)

(MaterialIcons comes from the icon package; any icon name works.)

UIText — a line in its role

Display, Title, Subtitle, Body and Caption take (string title, string? description = null) and return a TextComponent in that role. Label(string label) is the muted overline a thing is labelled by. Paragraph(string text) is prose that wraps, and Note(string text) a muted caption that wraps — the line under a heading that explains rather than names; both return a ParagraphComponent. A heading keeps one line and ends in an ellipsis, and so does its description: a TextComponent is a label, so SetWrapMode(UITextWrapMode.Wrap) lets its description run on and SetTitleWrap(true) its title — a heading in prose, an article's headline. A card's and an expander's default header wrap their description on their own.

The same roles exist as extension methods on any text component, for a text that is bound rather than written: AsDisplay(), AsTitle(), AsSubtitle(), AsBody(), AsCaption(), AsOverline(), and Muted(), which puts both lines in the muted colour.

UILayout.Stack(4,
    UIText.Title("Storage"),
    new TextComponent().AsCaption().Muted().BindTitle(nameof(AccountController.StorageLine))
)

UIDetails — names and values to read

UIDetails.List(params (string Key, string Value)[] rows) is a KeyValueActionComponent without the action column or a border of its own — an order's summary, a record's facts — for a card or a surface to hold. Rows are keyed by name, so a list that repeats a name throws.

UIDetails.List(("Plan", "Standard"), ("Region", "Europe West"), ("Billed", "Monthly"))

For values that change, bind the items instead and build each row with UIDetails.Row(string id, string key, string value), which returns a KeyValueActionItem whose key is in the muted colour:

// Controller
public RecursiveCollection<KeyValueActionItem> Lines { get; } =
[
    UIDetails.Row("plan", "Plan", string.Empty),
    UIDetails.Row("region", "Region", string.Empty)
];

// View
UIDetails.List().BindItems(nameof(CheckoutController.Lines))

Shown, hidden or enabled by another component

ShownWhen, HiddenWhen and EnabledWhen extend any component and watch the value of another one, named by its component id — so the source is created with an id (new CheckboxComponent(SameAddressId)). Each is one Interact (see interactions and effects), so the rule runs in the browser without a round trip to the server.

Call Holds while
ShownWhen(sourceId) / HiddenWhen(sourceId) / EnabledWhen(sourceId) The source has a value: a switch on, a box ticked, a select with a choice.
...When(sourceId, object? value) The source's Value equals value.
...When(sourceId, UIProperty source, UIComparisonOperator @operator, object? value) The named property of the source satisfies the comparison.

ShownWhen and HiddenWhen collapse the component when it is not shown; EnabledWhen disables it. The rule follows the reader's own edit of the source as well as a value the server pushes, so a switch turned on reveals its panel at once.

UILayout.Stack(28,
    new RadioGroupComponent(BilledId)
        .SetTitle("Billed")
        .SetOptions(
        [
            new OptionItem { Id = "direct", Title = "Directly" },
            new OptionItem { Id = "reseller", Title = "Through a reseller" }
        ])
        .BindValue(nameof(SubscribeController.Billed)),
    UIPage.Section("Company address", null, CreateAddress())
        .HiddenWhen(BilledId, "reseller"),
    new CheckboxComponent(TermsId)
        .SetTitle("I accept the terms")
        .BindValue(nameof(SubscribeController.TermsAccepted)),
    UIButtons.Primary("Subscribe")
        .EnabledWhen(TermsId)
)
