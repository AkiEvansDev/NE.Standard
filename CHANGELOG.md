# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.8.1

- **Input header actions (`SetHeaderAction` / `SetHeaderActions`)**: `InputHeaderActionExtensions` adds a `HeaderAction` region alongside `Title` on `InputComponentBase` and `InputTemplatedComponentBase` (refused only on inline `CheckboxComponent` and `SwitchComponent`, allowed on `MultiSelectVariant.Checkboxes`). `.ui-input__header-row` locks its height to `16px` (`--ui-text-caption-line-height`), compacts header buttons to `20x20px` around `16px` glyphs, and hangs the trailing quiet icon glyph flush with the field's right border without raising the label above actionless sibling fields.
- **Expandable `TextAreaComponent`, `ExpandFieldEffect`, and `FieldExpandExtensions`**: `TextAreaComponent.SetExpandable(Action<UITextAreaExpandBuilder>?)` (`IExpandableInputComponent`) adds a built-in header expand button (`SetShowButton(false)` to hide) that promotes the live DOM editor into a full-height client modal dialog — preserving caret, selection, `Undo`/`Redo` history, item-template row context, and bindings, moving `HeaderAction` controls into the dialog header before `×`, and applying expanded `Appearance` (`Outline` by default when inline is `Ghost`) and `Width` (`FieldExpandExtensions.SetWidth(UIColumnWidth)`). `ExpandFieldEffect` (`CanRunInInteraction = true`, compile-time checked against `IExpandableInputComponent`) opens the modal editor from any interaction or command result.
- **`UIDialogs.Fill` and `UIDialogs.BoundFill`**: new `NE.Standard.UI.Extensions` dialog presets (`Height = UILayoutLength.Fill()`, `Width = UILayoutLength.Fill()` unless `width: UIColumnWidth` is specified) with an `Auto` header row and a `Star(1)` content row without a `ScrollContainerComponent` wrapper, paired with stretched `TextAreaComponent` and `CodeInputComponent` filling the row height with `resize: none`.
- **In-field `SelectComponent`, `MultiSelectComponent`, and `SearchComponent` trailing actions**: trailing actions (`AddTrailingAction` / `SetTrailingAction`) render inside the trigger immediately before the rightmost `25px` divided chevron cell (`| ⌄`) without a second divider, keeping the chevron column aligned across sibling selects with and without actions.
