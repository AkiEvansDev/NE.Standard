# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.13.0

- **Built-in `MinLength`, `MaxLength`, and `Range` validation rule builders**: `InputComponentExtensions` adds `.MinLength(min)`, `.MaxLength(max)`, and `.Range(min, max)` overloads on `IInputComponent` with localized default messages in `UIStrings` (`ValueMinLength`, `ValueMaxLength`, `ValueRange` in English, Russian, and Simplified Chinese) as well as custom string and `UIPhrase` messages.
- **Dialog scoping, modal-aware lookup, side drawers, and `RequestLeaveAsync` in `NE.Standard.UI.Client` and `NE.Standard.UI.Testing`**: adds `Dialog(key)` handles on `UIClientPage` and `UITestPage`, modal-layer precedence and closed-dialog filtering on unscoped `ComponentNamed` and `ComponentBoundTo`, public `RequestLeaveAsync(target)` across `IUIClientTransport` / `UIClientPage` / `UITestPage`, side-drawer client state (`IsDrawerOpen`, `OpenDrawerAsync`, `CloseDrawer` with `OnDrawerOpen` dispatch), `ExpandFieldEffect` tracking, `PressNotificationActionAsync(ShowSystemNotificationEffect)`, `UITestRow.Slot(...)`, and accurate `IsShown` resolution for `EmptyTemplate`, closed `Flyout` / `ContextMenu` popups, and collapsed `Expander` / `CollapsiblePanel` bodies.
- **Wire serialization and `RemoteUIClientTransport` hardening**: adds `[JsonConstructor]` to `UIValidationMessage`, supports lossless string and object coercion for `ColorVariant` and `UIThemeColor` across `CompiledViewWireSerializer` and `RecursiveValueCoercion`, loads referenced `NE.Standard.UI.*` assemblies on demand when resolving effects and external types, chains inbound `ui.changes` and `ui.commandResult` pushes onto a strict FIFO queue across staged `/_ne/values` fetches, and arms session-key rotation synchronously on `UISessionKeyWireEffect`.
- **Web SSR hydration, input commit gates, Monday-first calendars, and plugin surface additions**: sequences `initializeItemsHosts` after initial word-table hydration in `WebUIRuntime.hydrate()`, aligns standalone and popup calendars on Monday as the default week start across cultures unless `FirstDayOfWeek` is set, records single-language `Relative` moment phrases and pre-paint `data-ui-tooltip` rewrites, wires `OnSubmit` form IDs and radio-group buffering across `FileInput` / `ImageInput` / `Search` / `RadioGroup`, updates `CommitGate` on calendar picks and resets per-field `FieldKeysEngine` drafts before `Escape` blur, defers `Slider` clamp checks until same-batch `Min`/`Max`/`Step` updates settle, observes mounted row height changes in `ItemsVirtualizationEngine`, and adds `tooltips.register(provider)`, `EffectContext.row` / `source`, `names.fileMaxSize`, and `dom.invalidate(scope?)` to the plugin contract (`ContractVersion` unchanged).
- **`NE.Standard.UI.Desktop`, file store, server endpoints, presets, and logging hardening**: adds `SanitizeWindowsFileName` and claim-before-dialog atomic `.tmp` downloads in `DesktopShellControl`, isolates Windows Toast callbacks across navigation epochs with cross-epoch `bringTo` routing, scopes loopback auth cookies per port (`ne.desktop.auth.<port>`) with `inproc` / `remote` default WebView2 sub-profiles and bounded `HasUnsavedWorkAsync` close checks, tracks streaming `StageDownloadAsync` quotas dynamically via `DownloadLease` alongside `IUIFileStore.GetTotalUploadedBytesAsync` and atomic `.tmp` overwrites in `TryDeliverDownloadAsync`, preserves `CategoryLevels` under `UIFileLoggerProvider` minimum levels, adds `TabCaptionRegion.Editable(string, ...)`, excludes internal drawer/dialog toggles from `WebViewRenderer.OwnOpeners`, and expands `NEUI018` shorthand and cross-file helper analysis.
