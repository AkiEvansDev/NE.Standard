# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.7.0

- **Breaking:** every package targets `.NET 11` (`net11.0`, `Microsoft.Extensions.*` and SignalR `11.0.0`, Roslyn `5.9.0` on `NE.Standard.UI.Generators`; building requires the `.NET 11` SDK).
- **Breaking:** view compilation refuses inline renaming (`SetRenamable(true)`, `BindRenamable`, `.Editable(...)`, `OnRename*`, `OnItemRename*`, `UITabMenuEntries.Rename`, or `RenameItemEffect`) with `InvalidOperationException` unless the renamed component or item template declares a writable (`TwoWay`, `OneWayToSource`, or `OnSubmit`) `BindRenamedTitle(...)` (`TreeNodeComponent(binds: true)` and `DefaultTabItemTemplate(binds: true)` bind `RenamedTitle` automatically).
- **Breaking:** `TabItemComponent.OrderProperty` and `PinnedProperty` default to `UIBindingScope.Relative` instead of `Root`, `TabItem.Pinned` defaults to `false`, `TabsViewComponent` sorts tabs by `Pinned` descending ahead of `Order`, and direct client writes to `Pinned` are refused (`Pinned` and `Order` updates are applied on the server by `tab-pin` when `UITabMenuEntries.Pin` is enabled).
- **Breaking:** `MapStandardUIWebAsync` no longer maps `GET /_ne/view` unless `WebEndpointOptions.EnableClientViewEndpoint = true` (`MapStandardUIServerAsync` still maps `/_ne/view` by default); `UITestApp.Create` defaults `DefaultViewCompilationMode` to `UIViewCompilationMode.Lazy`; and `TargetedClientEffect.Target`, `CopyToClipboardEffect.Target` and `ShowImageEffect.Target` are `[JsonIgnore]` on the wire in favour of `ResolvedTarget` (`ClientEffectJsonConverter`, `RawClientEffect`, and optional `includeDiagnostics` on `CompiledViewWireSerializer`).
- Added session and process download byte quotas on `UIFileOptions` (`MaxDownloadBytesPerSession` defaulting to `256 MB` and `MaxDownloadBytesTotal` defaulting to `4 GB`, `0` or `null` for unlimited), JSON payload depth/element/parameter bounds in `WebHubProtocol`, one-shot server grants for `RenameItemEffect` on non-`Renamable` targets, server folder and ancestor-cycle gates on `TreeComponent` drops, pinned-tab close refusal on `TabsViewComponent`, and `WebHubDisconnectFilter` suppressing SignalR error logs when a client disconnects mid-invocation.
- Closed `UIClientPage` and `UITestPage` parity gaps: added `RenameAsync(title)`, `page.Session`, `ClearEffects()` / `ClearDownloads()`, `ValidationInto` target routing in `ValidationMessage`, `BindContext` evaluation, client bounds holding, and stateful + automatic reconnect and client time-zone forwarding on `RemoteUIClientTransport`.
- Preserved multi-layer `SetDefaults<TDescendant>` overrides and cascaded them into view-declared and component-owned `UIDialog` trees, traversed layout-only containers when stamping `FormId` in `UIDialogs.Form`, deferred `SliderComponent` `Minimum`/`Maximum` range validation until view compile time so fluent setup order does not throw, and allowed `SetDescriptionPlain` / `SetDescriptionAutolinks` in `TextPresetExtensions` fluent chains.
- Linked standalone `<label for="...">` elements to focusable field controls, added `aria-label` fallback from `Placeholder` on unlabelled text fields, added live client patching for `UIMultiSelectVariant.Button` (`BottomEnd` popup placement default), capped `ImageInputComponent` (`UIImageInputVariant.Picture`) surface width on wide layouts, muted Ghost field-action rest ink until hover/focus, validated `FormId` controls on native Web form submit, enforced `UIOverflow.Hidden` `0 px` boundary clipping on Web and WPF surfaces and panels while preserving `data-ui-clip-reach` contour/glyph reach on unframed panels, gave compact `BadgeComponent` labels inline padding and a responsive square `min-width`, docked submenus opened from surface-framed on-page `MenuComponent`s flush against the surface border, and updated `UIGlyphs.Columns` to `checklist`.
- Improved compiler, runtime and Web host throughput: incremental Roslyn syntax/symbol caching in `NE.Standard.UI.Generators`, pooled runtime update coalescing and compiled `ItemContext` property getters in `NE.Standard.UI`, O(1) indexed row lookups in `UIClientPage`, and a static per-process precompression cache in `WebAssetCompression`.
