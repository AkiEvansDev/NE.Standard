# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.11.0

- **Side-drawer presets, `OnDrawerOpen` hook, single-column `UILayout.Panes`, and `ImageComponent.SetLazy(bool)`**:
  - **`UIPage.Drawer` / `UIPage.BoundDrawer` and `OnDrawerOpen`**: `UIPage.Drawer` and `UIPage.BoundDrawer` build full-height side-drawer panels with a fixed header row, `Pin`/`Close` controls, a scrollable body, and an optional footer; `.OnDrawerOpen(command)` / `.OnDrawerOpenLiteral(...)` (`DrawerOpenComponentExtensions`) on a view's `CreateLeftSide()` or `CreateRightSide()` root fires when an unpinned drawer opens without re-running on close or while pinned.
  - **Single-column stacked `UILayout.Panes`**: `UILayout.Panes(..., stacked: true)` with `new UIPanesState(stacked: true)` switches between list and detail in one column at every viewport width (including inside narrow drawers and cards) rather than splitting into two columns from `md`.
  - **Eager image hint (`ImageComponent.SetLazy(bool)`)**: `ImageComponent.Lazy` defaults to `true` (`loading="lazy"`); `.SetLazy(false)` omits `loading="lazy"` for above-the-fold images, avatars, and drawer thumbnails.
- **Stable `SliderComponent` readout width**: `.ui-slider__value` and `.ui-slider__values` reserve a fixed tabular width (`data-ui-slider-value-sizer`, horizontal `text-align: end`, vertical `text-align: center`, `white-space: nowrap`) computed across the stepped range envelope from `Min`, `Max`, and `Step` decimal precision on both initial SSR and live bound updates so dragging across digit-count transitions (`0.85` → `1` or `9` → `100`) never shifts `.ui-slider__track` or sibling vertical faders, plus rounded upper-bound step snapping in `snapToStep`.
- **Standalone headless `NE.Standard.UI.Server` beneath `NE.Standard.UI.Web`**: `NE.Standard.UI.Server` now owns the SignalR hub (`/_ne/hub`), compiled view wire endpoint (`/_ne/view`), file transfer endpoints (`/_ne/files`), value staging (`/_ne/values`), content (`/_ne/content`), localization (`/_ne/words`), session cookies/key rotation (`/_ne/session/key`), request guards, and hub filters/metrics directly without pulling HTML renderers or Web client assets, while `NE.Standard.UI.Web` layers SSR, asset bundles, and render caching on top (`[TypeForwardedTo]` preserves binary and source compatibility for `2.x` callers).
- **Single-endpoint HTTPS `DesktopWebHost` with per-process `HttpOnly` cookie gate**: `DesktopWebHost` serves `InProcess` `WebView2` windows over a single HTTPS `Http1AndHttp2` loopback listener (`BaseUri == BrowserBaseUri`) protected by a per-process 256-bit `HttpOnly; Secure; SameSite=Strict` cookie (`ne.desktop.auth`) seeded into `CoreWebView2.CookieManager` (plus `DesktopWebHost.CreateHttpClient()` for in-process HTTP callers), enforces same-origin top-frame bridge checks and external navigation interception, applies `UIStartupBuilder.ReadShellDefaults<TStartup>()` (`Theme` and `Icon`) in `Remote` mode, and hardens `ConfirmCloseAsync` and `DesktopShellControl` disposal.
- **Core, `Client`, and generator hardening**: enforces `MaxClientValueElements` and `MaxClientValueDepth` on `JsonElement` payloads, compares enums by wire name in `UIComparisonEvaluator`, validates modifier/multi-key chords in `UIKeyChord.TryParse`, aligns `NE.Standard.UI.Client` background command `Accepted` results, session-key rotation barriers, reconnect state resets, and `CompiledViewWireSerializer` type resolution, attaches non-field-backed `[RecursiveMember]` properties on classes with explicit constructors, and extends `NEUI018` to property initializers and constructor helpers.
