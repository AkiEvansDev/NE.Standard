# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.9.0

- **Default `NE` application icon and `SetIcon` / `SetNoIcon` startup API**: `NE.Standard.UI.Web` serves a built-in `NE` favicon (`/_ne/icon.svg`, `UIWebAssetKind.Icon`) and `NE.Standard.UI.Desktop` (`2.9.0-preview.1`) embeds a matching multi-size `icon.ico` (`16–256 px`) applied to `DesktopWindow.Icon` and defaulted as `<ApplicationIcon>` on `WinExe` consumers (`UseNESkipDefaultApplicationIcon=true` to opt out). `UIApplicationBuilder.SetIcon(string)` (`UIApplication.Icon`) configures a custom icon across hosts, `SetNoIcon()` (`UIApplication.NoIcon`) suppresses the default icon, and `WebEndpointOptions.Icon` / `DesktopHostOptions.Icon` (`--icon=<path>`) provide host-level overrides.
- **Responsive cross-axis `GridSplitterComponent`**: `GridSplitterComponent.Orientation` is now `UIResponsive<UIOrientation>`, allowing a splitter to switch between column splitting (`Vertical`) and row splitting (`Horizontal`) across responsive breakpoints (`SetColumn` / `SetRow` per-tier overloads), validated per tier at compile time and backed by tier-aware CSS track variables (`--ui-split-columns` / `--ui-split-rows`) and active-axis `ClientStore` / `BindPosition` reset in `GridSplitterEngine`.
- **Header-aligned `ExpanderComponent` actions**: `.ui-expander__header-action` centers vertically against the header's own title line height (`--ui-expander-header-line` via `data-ui-expander-header-line`, tracking `Subtitle`, `Caption`, and custom `TitleType` roles) with `4 px` vertical clip reach when `20 px` action buttons stand on a `16 px` caption header.
- **Scripted caret-input commit gate**: programmatic edits via `InsertTextEffect` (`.Literal`, `.CurrentItemKey`, `.CurrentItemValue`) and scripted `input` events on custom caret surfaces mark `CommitGate` dirty so un-debounced `TwoWay` / `OneWayToSource` inputs commit reliably on `blur`, `Enter`, or ahead of any server command (`EventPipeline.flushPendingFieldCommits`) while keeping `OnSubmit` fields buffered.
- **DemoApp button previews**: `/actions/button` and `/actions/split-button` default their interactive previews to `UITextAlignment.Start`.
