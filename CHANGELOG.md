# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.14.0

- **`UISelectVariant.Quiet` and single/empty `SelectComponent` popup locking**: `SelectComponent<T>` adds `Variant` (`UISelectVariant.Field` default, `UISelectVariant.Quiet` / `SetVariant`), rendering `Quiet` as a compact borderless `fit-content` trigger showing `Icon + Title` + chevron (`ui-select--quiet`, `CaptionRowBox` = `Small`) with `--ui-wash-hover` / `--ui-wash-active` feedback while opening full option rows in a content-sized popup (`minAnchorWidth: false`). Non-windowed single-value `SelectComponent` triggers now stamp `WebAttributes.SelectLocked` (`data-ui-select-locked` via `ItemsCollectionRendererBase.IsItemSelectable` on SSR and `syncSingleSelect` on the client) when `0` selectable options exist or `1` selectable option already matches `Value`, hiding `.ui-select__chevron`, setting `cursor: default`, and blocking popup opening while keeping `ShowClearButton` (`×` / `Delete`) and in-field actions live.
- **Compact `SliderComponent` geometry, split range readouts, row-box alignment, and thumb-lean feedback**: reduces horizontal `.ui-slider__row` and `.ui-slider__input` height from `40 px` to `24 px` (`Small` `20 px`, `Large` `32 px`) with even whole-pixel tracks and thumbs (`6 px` / `16 px` at `Medium`, `4 px` / `14 px` at `Small`, `8 px` / `20 px` at `Large`, symmetrically on vertical sliders), replacing the `4 px` `.ui-range-halo()` ring with thumb fill leaning toward `--ui-range-on-color` (`88%` on `:hover` / keyboard focus, `80%` on `:active`, `2px solid Highlight` under `forced-colors: active`). Range sliders (`IsRange && ShowValue && !ShowRange`) place start and end readouts on opposite ends of `.ui-slider__row`, and `SliderComponent.RowFieldBox` (`SetRowFieldBox`, inferred automatically by `UIViewCompilationContext` beside sibling field boxes or aligned controls) centers the horizontal track row on its row neighbor's height without inflating stacked sliders.
- **Flush ink-only `UIExpanderVariant.Quiet` (`UIPage.Fold`) headers**: removes the hover/focus/active wash pill and negative horizontal bleed margins and paddings on `.ui-expander--quiet > .ui-expander__header`, standing `Quiet` headers flush (`0 px`) with sibling controls and unfolded content and answering `:hover`, keyboard focus, and `:active` via text and chevron ink intensity alone (`@ui-text-muted` → `@ui-text-ink` → `var(--ui-text-selected)`, with a `2px solid Highlight` focus outline under `forced-colors: active`).
