# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.6.2

- **`UIItemsLayoutType.Accordion`**: `ItemsViewComponent.SetLayout(UIItemsLayoutType.Accordion)` over an `ExpanderComponent` item template coordinates single-expand across items on the client (expanding one item collapses the others) and joins the borders and outer corners of the currently visible items into a single connected stack across Web (`ItemsCollectionRendererBase`, `AccordionEngine`, `ItemsSpacers`) and WPF (`ItemsViewComponentRenderer`) as items are added, removed, reordered or filtered.
- **Auto-collapsing empty `IEmptyStateComponent` hosts**: When `SetShowEmptyTemplate(false)` is set on an `ItemsViewComponent`, `TableComponent`, `TreeComponent` or `KeyValueActionComponent` and its item collection has zero visible items, the host collapses its own root element (`display: none` on Web, `Visibility.Collapsed` on WPF) so it leaves no spacing or grid gap in a parent layout.
- **Submenu ancestor key matching in `OnItemClick(key, effect)` and `InsertTextEffect.CurrentItemValue`**: Row-keyed interactions (`InteractOnRow` / `OnItemClick(key, effect)`) in nested menus match any ancestor submenu group's `Id` in addition to the leaf entry's `Id`, and `InsertTextEffect.CurrentItemValue(target)` inserts the clicked item's `IMenuItemModel.Value` (`data-ui-menu-item-value`, falling back to its visible text) at the target field's caret without a server round-trip.
- **Collection intersection in `UIComparisonOperator.In` and `UIMultiSelectVariant.Button`**: `UIComparisonOperator.In` (and `NotIn`) in `UIComparisonEvaluator` and client `InteractionEvaluator` checks collection intersection when the left operand is a collection (including `IBindableItem` collections matched by `Id`), and `MultiSelectComponent.SetVariant(UIMultiSelectVariant.Button)` renders a compact button trigger (`SetVariant(UIButtonVariant)`, `SetIcon`, `SetTitle`, `SetSize`, `SetColor`, usable in `TextInputComponent.SetAction` / `TextAreaComponent.SetAction`) that opens the checkable option popup and displays the selected count as a badge on the button.
