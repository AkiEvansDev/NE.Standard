# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.10.0

- **`NE.Standard.UI.Desktop` graduates to stable `2.10.0`**:
  - **In-process `HTTP/2` loopback, `InMemoryWebViewRenderCache`, and zero-copy local file transfers**: `DesktopWebHost` serves `BrowserBaseUri` over `HTTP/2` with an ephemeral SPKI-pinned loopback TLS certificate (`DesktopLoopbackCertificate`), disables loopback Brotli/Gzip precompression, switches to `InMemoryWebViewRenderCache`, raises default desktop file transfer limits to `4 GB` per file / `16 GB` per session (`UIPlatformDefaults.ConfigureDefaultFiles`), registers local file uploads directly by path (`CoreWebView2File` → `IUIFileStore.RegisterLocalUploadAsync`) without copying bytes to `StorageRoot`, and delivers downloads directly to the chosen path (`IUIFileStore.TryDeliverDownloadAsync`) with language-neutral `SaveFileDialog` extension masks.
  - **Native Windows Toast system notifications and window visibility**: `DesktopShellControl` and `DesktopWindow` bridge `ShowSystemNotificationEffect` and DOM `Notification` to native `Windows.UI.Notifications` OS toasts (`DesktopHostOptions.AppUserModelId`, `SystemNotificationShown` / `DesktopNotificationShownEventArgs`) with the application's `WindowTitle` and extracted `.ico` PNG, auto-grant notification permission (`Context.NotificationPermission == Granted` on attach), sync `IsSurfaceVisible` (`WindowState != Minimized && IsActive`) to `document.visibilityState`, `HasVisibleViewers`, and `OnVisibilityChangedAsync`, and restore/foreground-activate the window while running `followClick` on toast click (including after `ToastDismissalReason.TimedOut` into `Win+N`).
  - **Localized in-page leave-guard close confirmation**: closing a `DesktopWindow` with unsaved work or pending field commits (`DesktopShellControl.ConfirmCloseAsync`, `WebUIRuntime.confirmCloseAsync`) flushes in-flight edits first and opens the framework's themed, localized `leave-dialog.ts` (`ui.leave.*` in the session's active language) instead of an unthemed OS `MessageBox`.
- **Streaming downloads, async pooled file store I/O, and content `ETag`s**: `IUIDownloadService.DownloadAsync` (`UIContext.Downloads.DownloadAsync`, `IUIDownloadStager.StageAsync`, `IUIFileStore.SaveDownloadAsync`) adds `Func<Stream, CancellationToken, ValueTask>` streaming producer overloads so large exports stream directly to disk without `byte[]` buffering; `FileSystemUIFileStore` uses `FileOptions.Asynchronous | SequentialScan` (`80 KB` buffers) and `ArrayPool<byte>` hashing; `IUIContentProvider.TryGetETagAsync` enables conditional `304 Not Modified` responses on `/_ne/content/{**key}` before opening streams.
- **HTTP value staging for large collection updates & server/client hot-path optimizations**: `ServerCollectionChangeUIUpdate` (`WebOutgoingValues`, `WebValueEndpoint`, `value-staging.ts`, `RemoteUIClientTransport`) stages oversized `Added` / `Updated` item batches over single-use `/_ne/values/{token}` pulls alongside full-value updates and pools incoming `/_ne/values` request reads; `WebShellRenderer` and `WebRenderMetadata` stream hydration JSON directly as UTF-8 into pooled `ArrayPool<byte>` buffers; `UIRuntime` deduplicates validation target pairs; client virtualized lists (`items-virtualization-engine.ts`) use `O(log N + visible)` binary search over prefix heights instead of `O(N)` scroll scans, `items-filter-sort.ts` caches resolved item search text across keystrokes, and `DomRegistry` fast-paths off-screen subtree lookups.
