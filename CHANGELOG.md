# Changelog

Each section below becomes the GitHub release body for that tag and is removed from this file after the release is cut; published history lives on the [Releases page](https://github.com/AkiEvansDev/NE.Standard/releases).

## 2.7.2

- **`ItemsViewComponent.RowBleed` and clickable-row cursor under `UISelectionMode.None`**: `ItemsViewComponent.SetRowBleed` / `BindRowBleed` aligns row content flush with the view's inline edges on vertical stacks with row hover or selection chrome while bleeding hover and selection pills `8 px` into parent padding (`Padding >= 8`, widening unframed ancestor clip reach to `Contour` and reserving `--ui-scroll-room-bleed`), and all four `IItemClickComponent` hosts (`ItemsViewComponent`, `TableComponent`, `TreeComponent`, `KeyValueActionComponent`) stamp `data-ui-row-click` for clickable rows (`cursor: pointer`, press ripple, and `.ui-items-view__item` padding click delegation, keeping `OnItemOpen`-only rows at `cursor: auto`), with `UIClientPage` and `UIClientRow` gating `CanSelect = false` only when the host selects rows.
- **Phone bottom-sheet pickers for temporal and colour inputs**: `DateInputComponent`, `DateTimeInputComponent`, and `ColorInputComponent` open their pickers as bottom sheets below `640 px` (`sheetSwipeHandleOnly`), and `TimeInputComponent` gains a phone-only time-wheel bottom sheet (`< 640 px`, including a `Start | End` switcher when `IsRange = true`) while keeping inline segment editing on desktop.
- **Closed-field hover parity, `SliderComponent` pointer feedback, and `MultiSelectComponent` badge chips**: closed `SelectComponent`, `MultiSelectComponent` (`Field` and `Badges`), and `ColorInputComponent` fields (`Filled`, `Outline`, `Underline`) keep their resting border and fill on pointer hover like `TextInputComponent`; horizontal `SliderComponent` tracks expose the full `24 / 40 / 48 px` row box as an interactive hit-target with thumb hover halos (`.ui-range-halo()`) across single and dual-thumb range modes; and `MultiSelectComponent` badge chips (`UIMultiSelectVariant.Badges`) keep their selection ring and badge text unclipped.
