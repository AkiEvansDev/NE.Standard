# Changelog

The framework's changelog — the `core` slice. Every package in the slice carries the same version and goes out together. This file
holds only what is not released yet, under `## X.Y.Z`: the release workflow cuts that section out as the body of the GitHub release
(a tag with no section fails the release), and the notes of every released version live there —
https://github.com/AkiEvansDev/NE.Standard/releases. Other slices keep their own beside their sources (`addons/<Name>/CHANGELOG.md`).

## 2.6.0

- Added inline text renaming on `TextComponent` (`IRenamableComponent`, `IRenamableItemsComponent`, `SetRenamable`, `BindRenamedTitle`, `OnRename*`), `UIText.Editable` and `TextPresetExtensions.Editable` presets in `NE.Standard.UI.Extensions`, and target-only `new RenameItemEffect(target)` without an item key across Core, Web (`TextRenameEngine`, `.ui-text__rename`) and WPF (`WpfTextStyleHelper`), opening an inline input of the same font and height (`0 px` layout shift) on double-click, `F2` when focused, or `RenameItemEffect` with automatic client rollback when a server command refuses the rename.
- Updated the default dark palette (`UIColorPalette.Dark`) for deeper ground contrast and clearer surface, hover and field separation across both standard and high-contrast displays (`Background` `#141414`, `Surface` `#222222`, `Border` `#323232`, `Mark` `#404040`, `OnBackground`/`OnSurface` `#E6E6E6`, `--ui-text-selected` `#F6F6F6`, `--ui-wash-hover-share: 8%` and `--ui-field-rest-share: 8%` on dark / `10%` on light on `Background` (`#252525`), and `--ui-field-ground-share: 12%` (`#3A3A3A`) with lifted `Border` (`18%`, `#454545`) and `Mark` (`24%`, `#515151`) on `Surface` panels, dialogs, popups and side drawers).
- Enlarged the centered `*` (`U+002A` `asterisk`) glyph in `GeistVariable.woff2` (`476 × 468`, matching operator `+` width and stroke weight at `centerY = 354`) so inline Markdown `*…*` markers and multiplication signs remain clearly legible at body and caption sizes.
- Dimmed the mobile system-bar colour (`--ui-window-foot` in `window-foot.ts`) with the active modal veil (`var(--ui-color-overlay)`) whenever a modal side drawer or modal dialog is open, painted `--ui-window-foot` in the open sheet's own ground when a bottom sheet (`[data-ui-sheet][popover]` such as a phone's context menu or list popup, or a bottom-placed dialog) stands at the bottom edge, gated toggle indicator `:active` ring/knob/lean rules (`toggle.less`) behind `@media (hover: hover)` so touch taps on phones do not flash white before toggling, and stopped unpinned slide-out side drawers at `bottom: env(safe-area-inset-bottom, 0px)` with a `1px solid var(--ui-color-border)` bottom hairline.
- Completed a full codebase audit across `Contracts`, `Core`, `Packages`, `Web` and `Wpf`: fixed `~` and `^` closing delimiter rules and bracketed image alt-text parsing in `UIInlineTextParser`, structural equality and collection normalization across value/item contracts, whole-number `double`/`float`/`decimal` to `Enum` coercion in `RecursiveValueCoercion`, item-scope property isolation in `UIClientRowContext`, `IsFocused`/`HasValue` and `DialogKey` evaluation in `UIFirstPaintEvaluator`, tail-item removal and dynamic item-value path registration in `UIRuntime.Updates`, `SliderComponentRenderer` description placement when `TickStep <= 0`, recursive region/slot traversal in `WebRenderMetadataValidator`, duplicate-key insert deduplication in `CollectionPatchEngine`, `isInert` guards across Web interaction engines, and `RowItemKey` scope filtering, `CopyComputedTextEffect` clipboard writes, `WpfRemoteItemModel` property hydration and `DownloadFileEffect` cancellation in `NE.Standard.UI.Wpf`.
